# Крестоносцы — история отряда

Сайт: https://krestarma.netlify.app/

Исходники опубликованной версии сайта игрового отряда «Крестоносцы».

## Где редактировать

- `index.html` — главный экран, раздел «Об отряде», галерея и участники.
- `app.js` — тексты глав по месяцам и интерактивные элементы.
- `style.css` — оформление и мобильная версия.
- `assets/` — изображения.

Файлы можно изменять прямо на GitHub: откройте файл, нажмите значок карандаша и сохраните изменения через **Commit changes**. Для обсуждения правок создавайте отдельную ветку и pull request.

## Публикация

Сайт состоит из готовых HTML, CSS и JavaScript. Сборка и установка зависимостей не нужны. Для Netlify: основная ветка `main`, команда сборки пустая, папка публикации `.`. Эти настройки папки также записаны в `netlify.toml`.

Репозиторий подключён к существующему проекту Netlify `krestarma`. Изменения в `main` автоматически публикуются по адресу https://krestarma.netlify.app/. Статус публикации проверяется в разделе Deploys проекта Netlify. Если публикация завершится ошибкой, посетители продолжат видеть последнюю успешно опубликованную версию.

Репозиторий публичный: не добавляйте в файлы пароли, токены или личные данные.

## Локальный просмотр

Откройте папку любым локальным веб-сервером, например `python -m http.server 8765`, затем перейдите на http://localhost:8765/.
